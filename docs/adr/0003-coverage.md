# 0003. Coverage: 198 profiled entities from a curated list

- Status: Accepted
- Date: 2026-10-27

## Context

The PRD says 193 in one place and 197 in another, and makes the Vatican clickable without covering
it. The M0 spike showed that a live Wikidata query for UN membership (P463 = Q1065, with no end
qualifier) returns 203 items:

- 10 of them are historical states with no end qualifier, such as "Kingdom of Laos" and
  "Mongolian People's Republic".
- Denmark's membership sits on the realm item (Q756617), which has no ISO code.

## Decision

- **Profile 198 entities:**
  - the 193 UN member states;
  - the 2 UN observer states (Holy See VAT, Palestine PSE);
  - Taiwan (TWN), Kosovo (XKX; it has no ISO 3166 code, so we use the user-assigned code that the
    World Bank and EU also use) and Western Sahara (ESH).
- **The list is curated and committed.** Each entry has a code, ISO2, Wikidata QID, kind and
  parent. It is reviewed by a person, not regenerated by a live query.
- **Sources never join on raw ISO3.** Each source resolves through the QID or a per-source code
  map, and rows that don't resolve are reported.
