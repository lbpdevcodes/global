# M0 spike results (2026-10-27)

## 1. Reader framework: React Router in JavaScript with a client-only globe

- **Result: works.** React Router is now at **v8** (8.5.1), not the v7 the plan assumed.
  Framework mode with `ssr: false` and `prerender` builds from plain `.jsx`. It writes
  `index.html` plus `__spa-fallback.html`, and globe.gl, loaded in `useEffect`, never runs at
  build time.
- **Gotcha:** Cloudflare Pages turns a `_redirects` rewrite that targets
  `/__spa-fallback.html` into a 308 redirect to `/__spa-fallback`. That URL matches no route,
  so the page rendered React Router's 404. The fix is to target `/__spa-fallback`. The e2e
  `e2e/shell.spec.js` now asserts that the deep-link URL stays `/country/FRA`.
- **Verified by** Playwright against `wrangler pages dev`, Cloudflare's local Pages runtime.

## 2. SQLite kept in R2 between runs

- `backend/bin/with-stored-database`:
  1. Fetches the database.
  2. Runs the command.
  3. On success only, uploads a consistent copy (`VACUUM INTO`) and a dated backup.
- If the fetch fails, the script refuses to start unless `ALLOW_EMPTY_DATABASE=1`. Otherwise a
  credentials failure would upload an empty database over the history.
- **Verified** by `spec/bin/with_stored_database_spec.rb` (5 examples), using a local-directory
  store. A failed run exits with the command's status and leaves the stored file byte-identical.
- **Not yet verified:** the `s3://` (R2) branch. It is two `aws s3 cp` calls and needs an R2
  bucket and credentials.
- **Production boot needs a secret.** With no `config/master.key`, `RAILS_ENV=production`
  fails with "Missing `secret_key_base`". The daily workflow (M2) must provide
  `RAILS_MASTER_KEY` or `SECRET_KEY_BASE` as a GitHub secret.

## 3. Borders build

- Natural Earth 1:50m v5.1.2 has 242 admin-0 features. All 198 profiled codes match a feature;
  Kosovo needs the `KOS` → `XKX` alias.
- **`ISO_A3` is `-99` for France and Norway** (and for Somaliland, Kosovo, N. Cyprus and
  Siachen). The build keys on `ISO_A3_EH`, falling back to `ADM0_A3`.
- **Microstates survive simplification** with `keep-shapes`: VAT, MCO, SMR, LIE, NRU, TUV, MDV
  and SGP all have polygons. They still need dots so they can be clicked.

- **45 features are not profiles.** They are territories (GRL, PRI, HKG…), breakaway areas

## 4. Source findings that change the plan

- **REST Countries v3.1 is deprecated.** It now returns an error pointing to v5. **v5 requires
  an account and an API key** (sent as `Authorization: Bearer`). The migration page does not
  publish field names, limits or terms. M1's first source needs a decision.
- **Wikidata UN membership is not a reliable seed.** The query returns 203 items, including 10
  historical states, and Denmark's membership sits on a realm item with no ISO code. The entity
  list is curated (ADR 0003).
- **Natural Earth's latest release is from May 2022** (ADR 0004 open item).
